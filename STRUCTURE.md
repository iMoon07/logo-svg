# Logo Folder Structure (organized)

Top-level categories (use these for browsing/manifest):

- `brands/` — brand & logo collections
  - `_curated/` — small hand-picked marks (site/quick use)
  - `simple-icons/`, `gilbarbara-logos/`, `devicon/`, `supertinyicons/`, `skill-icons/`
  - `selfhst-icons/`, `homelab-svg-assets/`, `dashboard-icons/`, `svgl/`
- `programming/` — languages, runtimes, frameworks, dev tools
- `stack/` — infra, DevOps, cloud, OS, virtualization, platforms
- `security/` — hacking, pentest, forensics, IDS/IPS, C2, defense tools
- `security-tools/` — OSS security tool marks (mostly raster)
- `security-enterprise/` — commercial vendors by product category
- `security-icons/`, `security-3d/`, `security-illustration/` — icon/3D/illustration sets
- `motion/` — animated glyphs/spinners (SMIL SVG, WebP)
- `networking/` — network devices/topology (router, switch, server, firewall, LB, cloud)
  - `network-automation/`, `bwks/`, `aci686/`, `minimalistic/`
- `industrial/` — OT/ICS/SCADA/HMI/PLC/process/electrical visuals
  - `fuxa-svg-widgets/`, `tchmi-vectors/`
- `iot-electronics/` — IoT/embedded/electronics boards, sensors, displays, comms
  - `usini-diagrams/`
- `hardware/` — IT hardware/device icon subsets (PC, CPU/chip, laptop, wifi, etc.)
  - `iconoir-devices/`, `lucide-devices/`, `tabler-devices/`, `carbon-devices/`, `fluent-devices/`
- `profession/` — profession/role icons
- `unicons-line/`, `unicons-solid/` — Unicons UI icon sets
- `icon-sources/` — provenance & license notes (`SOURCES.md`, per-source notes)

Notes: each imported collection keeps upstream license/SOURCE files in its folder. Brand logos remain trademarks of their owners. `electronics/` removed as duplicate of `iot-electronics/usini-diagrams`.
