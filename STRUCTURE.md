# Logo Folder Structure (organized)

Top-level categories (use these for browsing/manifest):

- `brands/` — brand & logo collections (`_curated/`, `simple-icons/`, `gilbarbara-logos/`, `devicon/`, `supertinyicons/`, `skill-icons/`, `selfhst-icons/`, `homelab-svg-assets/`, `dashboard-icons/`, `svgl/`, `lobe-icons/`, …)
- `programming/` — languages, runtimes, frameworks, dev tools
- `stack/` — infra, DevOps, cloud, OS, virtualization, platforms (incl. `kubernetes-community-icons/`)
- `security/` — hacking, pentest, forensics, IDS/IPS, C2, defense tools
- `security-tools/` — OSS security tool marks (mostly raster)
- `security-enterprise/` — commercial vendors by product category
- `security-icons/`, `security-3d/`, `security-illustration/` — icon/3D/illustration sets
- `motion/` — animated glyphs/spinners (SMIL SVG, WebP) incl. `svg-spinners-smil/`
- `networking/` — network devices/topology (`network-automation/`, `bwks/`, `aci686/`, `minimalistic/`, `ansible-networking-icons/`, `tmusabaika-minimalistic/`)
- `cloud/` — cloud architecture/service icon sets (AWS/Azure/GCP/Microsoft)
- `infrastructure/` — generic infrastructure/device/datacenter/protocol/security icon subsets (`ecceman-affinity/`, `mdi-device-infra/`)
- `industrial/` — OT/ICS/SCADA/HMI/PLC/process/electrical visuals (`fuxa-svg-widgets/`, `tchmi-vectors/`)
- `iot-electronics/` — IoT/embedded/electronics boards, sensors, displays, comms (`usini-diagrams/`)
- `hardware/` — IT hardware/device icon subsets (PC, CPU/chip, laptop, wifi, etc.)
- `mep-construction/` — MEP & construction/building services (HVAC, plumbing/sanitary, fire, electrical, partial civil/arch) with clear licenses (`electrical-symbols-chrismercredi/`, `knx-uf-iconset/`, `mdi-mep/`, partial)
- `electrical/` — electrical/electronic schematic & circuit symbols (`basverdoes-electrical-symbol-library/`, `circuit-symbol-svg/`)
- `utilities/` — utility/infrastructure symbols (`infrasym/`)
- `diagrams/` — diagram-provider icon sets (topology/infra/service, often PNG) (`mingrammer-*`)
- `scientific/` — scientific/laboratory/medical illustrations (`scisvg/`)
- `gis-mapping/` — map/POI/GIS icons (`maki/`)
- `civil-architecture/` — civil/architecture drafting aids & symbols (`freecad-symbols/`, partial)
- `profession/` — profession/role icons
- `unicons-line/`, `unicons-solid/` — Unicons UI icon sets
- `icon-sources/` — provenance & license notes (`SOURCES.md`, per-source notes)

Notes: each imported collection keeps upstream license/SOURCE files in its folder. Brand/cloud/vendor logos and official icon sets remain subject to their owners' trademarks and terms (see `icon-sources/SOURCES.md`). CC BY/CC BY-SA assets require attribution (and ShareAlike for BY-SA adaptations) as noted in per-collection SOURCE.md.
